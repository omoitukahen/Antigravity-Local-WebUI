# Antigravity Local WebUI

WindowsでAntigravity CLIを利用する、非公式のローカルWebUIです。履歴検索、会話の指示、Markdown表示、回答・会話のMarkdown/HTML保存、新規テキストファイル出力、停止制御、クォータ表示を備えます。Googleの公式製品ではありません。

**0.1.1 の対象はWindows 11 x64です。** Python 3.14・PowerShell 7・Antigravity CLIは別途導入してください。Windows 10、ARM64、他OSは未検証です。CLIの既存動作確認の基準版は1.3.0で、他版は未検証です。本配布版の自動検証は模擬CLIを使用し、実CLI診断・実モデル送信は行っていません。

## 1. 事前準備

1. [PowerShell 7](https://aka.ms/powershell-release?tag=stable) を導入します。
2. [Python 3.14 x64](https://www.python.org/downloads/windows/) を導入します。Python Launcherを使うか、PythonをPATHへ登録してください。
3. [公式の手順](https://www.antigravity.google/docs/quickstart?tab=cli) でAntigravity CLIを導入し、通常ターミナルで `agy` を起動して[利用者自身の認証](https://www.antigravity.google/docs/install?tab=cli)を完了します。
4. ZIPを、書込可能なローカルフォルダーへ展開します。ZIP内から直接実行しないでください。配置例は `C:\AI\AntigravityWebUI` です。長いパス・空白・特殊文字のためHookを起動できない場合は、このような短い配置先を使います。Program Filesやネットワークドライブは避けてください。

GitはZIP利用時には不要です。Node.jsは開発テスト専用です。通常利用ではGPU、CUDA、ローカルモデルの用意は不要です。依存パッケージの取得とCLIの外部接続にはネットワークが必要です。

## 2. セットアップ

`Setup.bat` を開きます。不足ソフトを自動導入することはありません。CLIの起動・診断・モデル送信も行いません。

明示的なパスが必要な場合は、このフォルダーをPowerShell 7で開いて指定します。

```powershell
& .\Setup.ps1 -PythonPath 'C:\Tools\Python314\python.exe' -CliPath 'C:\Tools\agy\agy.exe'
# 前提確認だけ。インストールや設定保存は行いません
& .\Setup.ps1 -CheckOnly
```

Pythonは明示指定、Python Launcherの3.14、PATHの順です。専用 `.venv` をこのフォルダーに作成し、全依存を `requirements.lock.txt` の版に固定して導入します。不適合な仮想環境は自動削除しません。

CLIは `webui.local.json` の明示指定、`%LOCALAPPDATA%\agy\bin\agy.exe`、PATHの順です。明示指定したCLIが存在しない場合に別のCLIへ自動切替はしません。指定を保存する場合は `Setup.ps1 -CliPath` を使います。標準の自動検出へ戻す場合は、アプリを終了してこの設定ファイルを退避してください。

BATは起動するPowerShellプロセスに限ってExecutionPolicy Bypassを指定します。利用者・システム全体の実行ポリシーは変更しません。組織のポリシーで禁止されている場合は管理者の運用に従ってください。

## 3. 初回設定と利用同意

`Start-WebUI.bat` を開くとブラウザーが起動します。「初回設定／構成の再確認」を開いて、次を実施します。

1. 表示された設定の読込元と環境変数名を確認します。CLI側の `/hooks`、`/plugin`、MCP、Sidecars、skills/rules、追加の読込元も確認します。未知の読込元がある場合は確認を完了させないでください。
2. 認証方式・接続先を、秘密値を含めずに入力します。プロキシ・接続先上書きの有無を確認します。
3. WebUIのガード以外の外部の実行可能カスタマイズをCLI側で無効にし、確認欄にチェックします。WebUIが既存のCLI設定や認証を変更することはありません。検出可能な外部Hooks・Plugins・MCP・Sidecarsや解析不能な設定がある場合は有効化しません。表示一覧だけで全読込元を検証済みとは扱いません。
4. 「接続を確認」を押します。CLIのバージョンとモデル一覧だけを時間制限付きで取得します。推論や質問の送信は行いません。失敗しても自動再試行しません。
5. 使用するモデルと考える量を選び、通常回答の利用に同意します。テキスト出力も使う場合はその同意欄も選び、「確認内容に同意して有効化」を押します。

この記録は、このPCでの構成確認・利用同意です。**実モデル試験の合格を意味しません。** CLI・アプリ・関連設定が変わると送信は無効になり、再確認が必要です。新しく一覧に加わったモデルは自動許可せず、一覧から消えたモデルの履歴は閲覧・保存できます。

通常回答・テキスト出力の許可は `data/local-setup.json` に保存します。認証トークンやAPIキーは保存しません。CLI自体の認証はCLIに任せます。既存の運用承認・完全受入方式の記録は、新規記録を作成しない限り従来の判定経路で使います。新規記録が不正な場合に旧方式へ戻って送信を許可することはありません。

## 4. 起動・終了と通常利用

- 起動：`Start-WebUI.bat`。終了：`Stop-WebUI.bat`。
- 模擬確認：`Start-WebUI-Mock.bat`。実モデルは使いません。初回設定の同意は保存しません。
- ブラウザーを閉じてもサーバーは残ります。終了用BATで停止してください。
- 接続は `127.0.0.1` の空きポートだけです。スマホや他PCからの接続、インターネット公開には対応しません。
- 起動リンクの認証情報はブラウザーのタブへ取り込みURLから除去します。他人へ共有しないでください。同じ起動中は二重起動を拒否します。
- 「新しい会話」でモデル・考える量・出力先・会話の指示を選び、質問を送信します。初回送信後はモデル・出力先・指示が固定されます。
- 添付はその送信に選択したテキストだけです。入力、添付、会話の指示はCLIを通じて外部サービスへ送信されます。利用するサービスの取扱いを確認してください。
- 実行は一度に1件です。停止ボタン、時間上限、画面との接続切れによる停止があります。自動再送・自動再開はしません。
- 実行を開始・引き継いだ画面は、生成ストリーム接続とheartbeatで接続を確認します。別タブへの移動中もストリームが接続していれば継続します。切断後は通常15秒の猶予で停止します。PCのスリープやタブ休止で接続自体が切れた場合は停止し得ます。
- 長文の途中回答は75msまたは8KiB単位で保存し、表示は100ms単位で更新します。正常終了時はCLIの最終回答で確定します。強制終了・PC障害時には未保存の末尾が失われる場合があります。
- 履歴検索、名前変更、お気に入り、回答コピー、会話削除、Markdown/HTML保存を利用できます。HTMLはサニタイズし、外部画像は読込みません。

## 5. テキスト出力と保存場所

「テキストの保存先」で既存のローカルフォルダーを登録し、新規会話の出力先に「テキストファイル」を選びます。例：「小説本文をNovel.txtに書き出してください。チャットへの長文出力は不要です。」

登録フォルダー直下の新規 `.txt` だけを許可します。同名は `Novel (2).txt` のように連番を付け、既存ファイルを上書きしません。出力は空でないUTF-8・最大1MiBです。本文はチャットへ転記せず、実ファイル不在を成功扱いにしません。ネットワークパス・リンク・アプリのdata管理領域内は登録できません。

会話を削除しても、登録フォルダーへ出力したファイルやダウンロード済みコピーは残ります。会話別の旧作業領域内にある出力は会話削除の対象です。「保存先を開く」は、このPCのExplorerを開きます。

| 場所 | 内容 |
|---|---|
| `data/history.sqlite3` | 会話、実行、添付情報、イベント、出力先設定 |
| `data/attachments/` | 添付本文 |
| `data/workspaces/` | 会話別のCLI作業領域、Hook、会話の指示を反映したAGENTS.md |
| `data/local-setup.json` | 構成確認と利用同意。別PCへコピーして有効化しないでください |
| `data/runtime.json` | 起動中だけの接続情報・秘密トークン |
| `webui.local.json` | この配置先のCLI指定 |

会話の指示の正本はDBです。AGENTS.mdを直接編集してもDBに反映されません。CLI自身の会話保存・ログ・認証情報は別管理です。

## 6. クォータ表示の準備

初回設定に表示される `data/diagnostics/quota` をExplorerで作成し、そのフォルダーを通常のターミナルで開いて `agy` を起動します。フォルダーの信頼確認を利用者が行い、質問を送らず終了してください。プロファイル全体を信頼する必要はありません。

信頼設定の変更後は、WebUIの初回設定で接続確認と同意をやり直します。WebUIはCLIの `trustedWorkspaces` を変更しません。準備が不足していても通常回答とテキスト出力は使えます。

「クォータを確認」を押したときだけ、専用ワーカーが固定の `/usage` を実行します。アカウント表示を除外し、既知の見出し・残量・リセット表示だけを抽出します。未知の形式や不完全な表はエラーにします。定期取得・自動再試行・トークン数からの残量推計は行いません。

## 7. 更新・バックアップ・削除

更新前に終了用BATで停止し、フォルダー全体をバックアップしてください。バックアップには個人の会話・添付・起動情報を含み得るため、公開しないでください。終了済みの `data/` をコピーすればSQLiteの関連ファイルも保持できます。

更新は新しいZIPを別フォルダーへ展開し、仮想環境を新規作成します。継続利用する場合は終了済みの旧 `data/` と必要なローカル設定だけをコピーし、初回設定で構成を再確認します。`.venv` はコピーしません。同じ履歴を2つの配置先から同時に使用しないでください。

アプリ削除は、停止・必要なバックアップ後に展開フォルダーを削除します。登録先へ出力したテキスト、ダウンロード済みファイル、CLI自身の認証・履歴・インストールは残ります。

## 8. 問題解決

- **Python/PowerShellがない**：上記の公式配布先から手動導入します。明示的なPython指定には `-PythonPath` を使います。
- **CLIがない／別のCLIを使いたい**：`Setup.ps1 -CliPath` で指定し、再起動します。CLI未導入でも模擬モードは使えます。
- **起動しない**：BATのメッセージと `data/launch-*.err.log` を確認します。ログを共有する前に個人情報・秘密値を除去してください。
- **送信できない**：初回設定の不足、構成変更、未同意モデル、テキスト保存先の未登録を確認します。
- **外部カスタマイズの検出**：CLI側で無効化し、読込元を確認してから再確認します。確認欄へのチェックだけでは検出された設定を無視できません。
- **Hookのパスを起動できない**：短縮名が使えない環境では、空白・特殊文字のない短い配置先へ移して再セットアップします。
- **クォータが失敗する**：専用フォルダーの信頼、通常CLIの認証、構成変更、対応画面形式を確認します。
- **応答が停止した**：理由を確認してください。自動再送しません。WebUIが管理するローカルプロセスの停止と、送信済みクラウド処理の即時取消は同じではありません。

1送信がCLI内部で1モデル呼出しになる保証はありません。CLI内部の再試行や利用枠の消費量もWebUIでは保証しません。

構成検査は起動・明示的な確認・生成開始直前に行います。定期status表示は最後に検査した状態です。CLIや設定を変更した直後には表示が以前の状態でも、生成開始直前の検査で拒否されます。

監視対象はCLI・Python環境・アプリ資産に加え、`~/.gemini/AGENTS.md`、`GEMINI.md`、`config/`、`antigravity-cli/` 配下の `.agents`・`.agent`・`builtin`・`rules`・`skills`・`plugins`、ユーザーおよび作業領域の祖先の `.agents`・`.agent` と指示ファイルです。ディレクトリ内の追加・削除・改名・内容変更も対象です。会話データやキャッシュを監視するためにユーザープロファイル全体を走査することはありません。独自の外部読込元は従来の `data/configuration-review.json` の `watch_roots` へ登録して確認してください。読込元を網羅したことを実CLIで自動証明する機能ではありません。場所の基準は公式の[ルール](https://www.antigravity.google/docs/rules)、[スキル](https://www.antigravity.google/docs/skills)、[プラグイン](https://www.antigravity.google/docs/plugins)仕様です。

## 開発・配布物の再生成

```powershell
& .\.venv\Scripts\python.exe -m pytest tests -q
node --test tests/*.cjs
& .\.venv\Scripts\python.exe scripts/check_architecture_freshness.py
# 変更をコミットした後に生成。実CLIもモデルも起動しません
& .\scripts\build-release.ps1
```

`releases/` にZIP、SHA-256、コミットIDと同梱一覧のmanifestを作成します。コミット済みの明示的な同梱一覧を使い、個人設定、履歴、ログ、仮想環境、生成物、Git履歴は含めません。GitHubへ履歴ごと公開する場合は、別途過去のコミットの秘密情報・個人情報を確認してください。

AI向け探索索引は `docs/architecture-agent-index.json` です。鮮度検査が失敗した場合は現行ソース・テストを参照します。索引は実機受入や実行中の構成状態の証明ではありません。

`Convert-Llama-JSONL.html` は、同梱staticと一緒に置いてブラウザーで開くオフライン変換ツールです。llama.appの単一会話JSONLをHTMLへ変換し、Python・CLI・ネット接続は不要です。
